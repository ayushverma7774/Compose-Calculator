Jetpack Compose Calculator
A modern, visually appealing Android calculator application built entirely with Kotlin and Jetpack Compose. The app features a standard 4x5 grid layout inspired by the official Android calculator, combined with a custom "glassmorphism" UI design over a background image.

✨ Features
Core Operations: Supports addition, subtraction, multiplication, and division.

Advanced Operations: Includes percentage calculation (%) and positive/negative sign toggling (+/-).

Dual-Field Input: Features distinct, interactive input fields for the first and second numbers. Users can click on either field to make it active.

Modern UI/UX:

Adaptive, perfectly circular buttons that scale to fit any screen size.

Semi-transparent dark glass effect on the input fields for maximum readability against custom background images.

Bold, dynamic result text that updates instantly.

Error Handling: Built-in safeguards against division by zero and invalid inputs.

🛠 Tech Stack
Language: Kotlin

UI Toolkit: Jetpack Compose

Layouts: Utilizes proportional weights (35% display, 65% keypad) for perfect scaling across all Android device screens without hardcoded pixel heights.
